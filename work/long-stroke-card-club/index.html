Long Stroke Card Club

Project type
Online gaming
Deliverables
Infrastructure · Admin interface · Payments

Long Stroke Card Club is an online gaming club. COET set up the infrastructure it runs on and built the interface its operators use to manage the site, including payments.

Product context

Operators need one place to run everything.

An online club has many moving parts: the site, its settings, its players and its money. The work was a dependable foundation and a single interface to manage them.

COET's contribution

  • Infrastructure

    The hosting and services the club runs on, set up for the operators to use.

  • Admin interface

    One interface to manage the various parts of the site.

  • Payments

    Payment management inside the same interface.
